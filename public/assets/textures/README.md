# Texturas adicionales

Las texturas de pintura, micro normales, neumáticos, AO e interior están embebidas en los GLB del directorio `../car/`. La estrella es una textura procedural pequeña creada en memoria; no hay una imagen fija de estrellas.

Para futuras texturas de detalle usar mapas PBR legalmente reutilizables, preferentemente CC0 de ambientCG o Poly Haven, de 1K para LOW y 2K como máximo inicial para HIGH. Registrar sus datos en `ASSET_LICENSES.md`. No añadir recursos de licencia incierta ni dependencias de una CDN en tiempo de ejecución.
