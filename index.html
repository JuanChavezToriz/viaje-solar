Cómo explorar

Abrir la experiencia Auto orbital ↗
  • Arrastra para girar.
  • Clic derecho para mover la vista.
  • En «Opciones» puedes acercar o girar la vista.
  • Selecciona el vecindario o un planeta.
  • Espacio: pausar. Esc: volver al sistema.
  • Desliza hacia arriba para continuar el viaje.
  • Arrastra el planeta para girarlo y pellizca para acercarlo.
  • Desliza la ficha de lado para cambiar de planeta.
  • En «Opciones» puedes cambiar el acercamiento.
  • Toca un planeta para conocerlo.
  • «Destinos» regresa a la vista de todos los planetas.
